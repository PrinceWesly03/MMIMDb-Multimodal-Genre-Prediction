# MMIMDb - Multimodal Movie Genre Prediction

## 1. Project Overview

This project investigates multimodal machine learning for predicting movie genres using movie posters and plot descriptions.

Movie genre prediction is a multi-label classification problem because a movie can belong to multiple genres simultaneously.

The project compares image-based, text-based and multimodal approaches to evaluate whether combining visual and textual information improves genre prediction.

## 2. Dataset

**Dataset:** MMIMDb (Multimodal IMDb)

The dataset contains:
- 25,959 movies
- 23 movie genres
- Movie poster images
- Movie plot descriptions
- Multi-label genre annotations

### Dataset Split

| Dataset | Number of Movies |
|---|---:|
| Training | 18,148 |
| Validation | 3,908 |
| Testing | 3,903 |
| Total | 25,959 |

## 3. Feature Extraction

### Image Features - ResNet-50

ResNet-50 is used to extract visual representations from movie posters.

Each poster is represented by a 2,048-dimensional feature vector.

### Text Features - DistilBERT

DistilBERT is used to extract contextual representations from movie plot descriptions.

Plot descriptions are tokenised, truncated or padded, and processed through DistilBERT.

Attention-mask-aware mean pooling produces a 768-dimensional feature vector for each movie.

## 4. Models Implemented

Four approaches were evaluated.

### Model 1: Poster-only

Uses 2,048-dimensional ResNet-50 image features to predict movie genres.

### Model 2: Plot-only

Uses 768-dimensional DistilBERT text features to predict movie genres.

### Model 3: Early Fusion

Combines image and text features through concatenation.

- Image features: 2,048 dimensions
- Text features: 768 dimensions
- Combined features: 2,816 dimensions

The classifier uses fully connected layers, ReLU activations and dropout.

### Model 4: Late Fusion

Combines the prediction probabilities generated by the poster-only and plot-only models.

Equal-weight probability averaging is applied:

P(late) = 0.5 * P(image) + 0.5 * P(text)

## 5. Training and Evaluation

The neural network classifiers use:
- PyTorch
- Binary cross-entropy with logits
- Adam optimiser
- Training and validation datasets
- Model checkpoint selection based on validation loss

The models are evaluated using:
- Micro-F1
- Macro-F1
- Macro Average Precision (Macro-AP)

A classification threshold of 0.5 is applied for F1 evaluation.

## 6. Experimental Results

| Model | Micro-F1 | Macro-F1 | Macro-AP |
|---|---:|---:|---:|
| Poster-only | 0.4142 | 0.2055 | 0.3358 |
| Plot-only | 0.2661 | 0.0401 | 0.1885 |
| Early Fusion | 0.4344 | 0.2023 | 0.3452 |
| Late Fusion | 0.3367 | 0.0806 | 0.3627 |

### Key Findings

- Early Fusion achieved the highest Micro-F1 score (0.4344).
- Poster-only achieved the highest Macro-F1 score (0.2055).
- Late Fusion achieved the highest Macro-AP score (0.3627).
- Plot-only performed worse than the poster-only baseline across all three metrics.
- Combining image and text information improved some evaluation metrics, but no single fusion method performed best across all metrics.

## 11. Limitations

- The dataset contains an imbalanced distribution of movie genres.
- Less frequent genres are difficult to predict.
- Some movies have multiple genre labels.
- Fixed classification thresholds may not be optimal for every genre.
- Late Fusion uses equal weights rather than learned or validation-optimised weights.
- Pre-extracted features limit task-specific adaptation of the image and text encoders.

## 15. Conclusion

This project demonstrates the application of multimodal learning to multi-label movie genre prediction.

Early Fusion produced the highest Micro-F1 score, suggesting that combining visual and textual features can improve overall classification performance.

However, the poster-only model achieved the strongest Macro-F1, while Late Fusion achieved the highest Macro-AP.

The results demonstrate that multimodal fusion effectiveness depends on the evaluation metric and that class imbalance remains an important challenge.
